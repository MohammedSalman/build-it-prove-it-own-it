# Build It. Prove It. Own It.
### Software engineering in the age of coding agents

Course materials for a 14-week software engineering course, plus an optional extension week.

**Start here:** the course website at https://mohammedsalman.github.io/build-it-prove-it-own-it/

## What is in this folder

```
site/                     the course website: course home and one chapter per week
starter/afterhours/       the AfterHours app you start from in Week 1
lectures/<week>/          each week's lab worksheet (lab-NN.md) and lab kit (lab-kit/)
plan/product-checklist.md what your team's AfterHours must meet, week by week
plan/class-dataset.md     how you record your minutes at the end of each lab
```

This folder is the `COURSE` folder the labs refer to. Get it once with **Code → Download ZIP**,
or with `git clone https://github.com/MohammedSalman/build-it-prove-it-own-it.git`.

## Before Lab 1

You need Python 3.11 or newer and git. Each lab kit has a README with commands for
macOS/Linux and Windows PowerShell.
